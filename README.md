# Mirage

A modern script built specifically for Red Hive autofarming in Bee Swarm Simulator.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/kingstawww/Mirage/main/main.lua"))()
```

---

While scripts like Atlas collect tokens decently, Red Hives depend heavily on token priority. Missing an important mark or ability token during a boost drops your multipliers and costs billions.

Mirage features flexible priority configuration, allowing you to easily customize token priorities to match your setup and maximize overall honey.
